# Security Policy

## Reporting a Vulnerability

If you find a vulnerability in cluster-health-analyzer, please report it
privately to Red Hat Product Security at secalert@redhat.com.

Please include as much of the following information as possible:

- A description of the vulnerability
- Steps to reproduce the issue or a proof of concept
- The potential impact
- A proposed severity rating (see
  [Red Hat's severity ratings](https://access.redhat.com/security/updates/classification/))
- Any relevant [CWE](https://cwe.mitre.org/) IDs or
  [CVSS](https://www.first.org/cvss/) scores

For more details on Red Hat's security response process, see
[Red Hat Product Security contacts and procedures](https://access.redhat.com/security/team/contact/).
